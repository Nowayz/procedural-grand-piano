# Small Hall Tail impulse response

`small-hall-tail.wav` is a 44.1 kHz/16-bit stereo conversion of **Synth Room
Gen 1 Size 4 (Tail Only).wav** from [Conner's Impulse Response
Library](https://github.com/itsmusician/IR-Library). The source file is 96
kHz/24-bit stereo and has SHA-256
`d5ef49123953169ef099b8b12a8e762047f8042f52d8a78bc57da9b179bf7c8f`.
