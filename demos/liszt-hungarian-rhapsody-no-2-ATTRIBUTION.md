# Liszt — Hungarian Rhapsody No. 2

The performance sequence used for `liszt-hungarian-rhapsody-no-2-procedural.wav`
is checked in as `scores/liszt-hungarian-rhapsody-no-2.mid`. It was created by
Bernd Krueger and downloaded from Wikimedia Commons:

https://commons.wikimedia.org/wiki/File:Liszt_-_Hungarian_Rhapsody_No._2.mid

The sequence is licensed under Creative Commons Attribution-ShareAlike 3.0
Germany (CC BY-SA 3.0 DE):

https://creativecommons.org/licenses/by-sa/3.0/de/deed.en

Modification: the MIDI performance was synthesized with this project's
procedural physical piano renderer and its Small Hall convolution reverb.
This adapted audio is distributed under CC BY-SA 3.0 DE.

Render it from the repository root with:

```sh
npm run track:midi -- scores/liszt-hungarian-rhapsody-no-2.mid demos/liszt-hungarian-rhapsody-no-2-procedural.wav
```

The underlying composition by Franz Liszt (S.244/2, first published in 1851)
is public domain.
